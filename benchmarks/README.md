# Benchmarks

Benchmark experiments generated by rules from an external problem library (ADR 0012).
For now that library is [S2MPJ](https://github.com/GrattonToint/S2MPJ) (Gratton &
Toint, [arXiv 2407.07812](https://arxiv.org/abs/2407.07812)), the Python version of
the CUTEst problems.

```bash
pixi run benchmark hs27 [--n-runs 3 --plot ...]    # run one, like any experiment
pixi run -e benchmarks generate-s2mpj [NAMES...]   # regenerate (fetches S2MPJ)
```

| file | what it is |
|---|---|
| `s2mpj/<name>.py` | one generated benchmark experiment per problem; never edited by hand |
| `s2mpj/SUITE.md` | every in-scope problem, generated or refused with the reason |
| `generate_s2mpj.py` | the rules below, the expression printer, and the writer |
| `s2mpj_experiment.py.template` | the text of every generated file |
| `s2mpj_source.py` | the only module that touches S2MPJ: reads and traces a problem |
| `fetch_s2mpj.py` | fetches S2MPJ at its pinned commit into the git-ignored `.s2mpj/` |

**Never edit a generated file.** To change a rule, or how experiments are written
(a new `hb` API, a different comment), change `generate_s2mpj.py` or the template.
Then raise `GENERATOR_VERSION`, regenerate every file, and check that the diff is the
one you meant. A test regenerates every committed file and compares it byte for
byte, so a hand edit fails the tests.

## How an S2MPJ problem is split

S2MPJ stores each problem in group-partially-separable form. Each constraint is a
group: a linear part, plus a weighted sum of nonlinear *elements*, minus a constant.
That passes through a group function and is divided by a scale. The rules turn an
equality-constrained problem

    min f(v)  subject to  c(v) = 0,  over S2MPJ's n variables v with m constraints,

into a hybrid problem with one unknown equation (P = 1). They work in this order
(`split` in `generate_s2mpj.py`), and the first rule a problem fails refuses it with
a `Reason`.

1. **Scope.** The problem must have:
   - equality constraints only (`INEQUALITIES` otherwise; #179);
   - n > m (`NO_DEGREES_OF_FREEDOM`);
   - a nonlinear constraint with elements (`ONLY_LINEAR_CONSTRAINTS`);
   - exactly one numeric `# LO SOLTN` in its file (`NO_SOLUTION`).

   The suite also takes only problems with an objective and n ≤ 10, as S2MPJ builds
   them by default.
2. **The hidden constraint.** One of those nonlinear constraints, j, is picked at
   random. The seed comes from sha256 of the problem name (`rng_of`), so every
   process and platform picks the same one; Python's `hash` would differ between
   processes. The pick is the first draw, so it doesn't depend on IPOPT.
3. **The hidden term and the equations.**
   - The hidden term N_j, the weighted sum of constraint j's elements, is the unknown
     state y. The oracle is y = h = N_j(v), and the `h_inputs` are its elements'
     variables.
   - The known equations g are every constraint as S2MPJ states it, with N_j
     replaced by y in constraint j.
   - Hiding the whole constraint instead would make every measurement read 0.

   If constraint j is its hidden term plus a constant (HS7: `(1 + v1²)² + v2² - 4`),
   the known equation is `y - 4 = 0`. It contains no variable, so no state is
   determined by it, and the problem is refused (`HIDDEN_TERM_IS_CONSTANT`).
4. **The solution.** IPOPT solves the full, known problem from S2MPJ's start point,
   within S2MPJ's bounds. If it fails, the reason is `IPOPT_FAILED`. Its optimum
   must match the stated SOLTN to a relative 1e-5 (`IPOPT_DISAGREES` otherwise). v*
   is rounded to 6 decimals, so IPOPT's last digits change nothing below.
5. **The bounds.** S2MPJ's finite bounds are kept. Each infinite bound becomes the
   edge of the hull of S2MPJ's start and v*, widened by max(1, half the hull's
   width), so the bounds contain the optimum without being centered on it. The trace
   is checked against S2MPJ's float evaluation at the start, at v*, and at 20 random
   points within these bounds (`UNTRACEABLE` otherwise).
6. **The states.**
   - The m mechanistic states are the variables that a column-pivoted QR of dg/dv
     picks, at v* with y held at N_j(v*). The root-finding problem solves g for the
     states with y measured, so g must determine them. With dc/dv, HS6 picks a state
     that g doesn't contain.
   - On a tie, the variable outside the hidden term wins, so that h depends on the
     decision variables where it can.
   - Both ∂g/∂x and ∂c/∂x (which the oracle simulation solves) must have a condition
     number of at most 1e8 (`ILL_CONDITIONED` otherwise).
   - The other d = n − m variables are the decision variables u.
7. **The variables' bounds.**
   - The decision variables are bounded by step 5's bounds.
   - The mechanistic states keep S2MPJ's bounds, and take step 5's as their start
     bounds.
   - y's start bounds are the hidden term's range over 256 Latin hypercube points
     within step 5's bounds, rounded out to 6 decimals.
8. **The oracle optimum** is the stated SOLTN, never a value a study computes.

**Configurations**, with d decision variables:
- hybrid BO with SAA-EI and with SoftSAA-EI, standard BO, and Latin hypercube
  sampling;
- each with 10d evaluations, 2d + 1 of them initial points, and 25d scenarios;
- a noise-free prior GP (Matérn 5/2, fitted output scale and lengthscales);
- SoftSAA's temperature is 1e-3 if the stated f* is exactly 0, else
  max(1e-3 |f*|, 1e-6).

## HS27, worked through

`min 0.01(v1 − 1)² + (v2 − v1²)²` subject to `CON1: v1 + v3² + 1 = 0`. S2MPJ's start
is `(2, 2, 2)`, and f* = 0.04 at v* = `(−1, 1, 0)`.

| | value | why |
|---|---|---|
| hidden constraint | CON1 | the only nonlinear constraint |
| y = h | `X3²` | CON1's one element (`eSQ`); `h_inputs` = X3 |
| g | `1 + X1 + y = 0` | CON1 with y in place of its element |
| state x | X1 | dg/dv = `[1, 0, 0]` with y held |
| decision variables u | X2 in [0, 3], X3 in [−1, 3] | hull of 2 and v*, widened by 1 |
| X1's start bounds | [−2.5, 3.5] | hull of 2 and −1, widened by 1.5 |
| y's start bounds | about [0, 8.93] | X3² over the bounds |
| budget | 20 evaluations, 5 initial, 50 scenarios | d = 2 |
| temperature | 4e-5 | 1e-3 × 0.04 |

The state has the unique root x = −1 − y, and the hidden term reaches f through x.
The generated file is [`s2mpj/hs27.py`](s2mpj/hs27.py).
